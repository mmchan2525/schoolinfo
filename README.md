# おたよりポスト (Otayori Post) - 英語おたより翻訳＆行事・持ち物管理

学校・インターナショナルスクールから届く**英語のおたより（Newsletter, Event Notice, Permission Slip等）**を写真やテキストでポストするだけで、AIが直接読み取り、**自然な日本語への翻訳 ＋ 予定・持ち物・提出締切の自動抽出**を行うWebアプリケーション（PWA）です。

---

## ✨ 主な機能

1. **OCRを使わないAIダイレクト読取 ＆ 高精度日本語翻訳**
   - 英語のプリント画像やテキストをAIに直接読ませてテキスト化・翻訳・JSON構造化を一括処理。
   - 学校特有の英語表現（"Permission Slip", "Field Trip", "Early Dismissal", "Packed Lunch" 等）を日本の保護者向けに分かりやすく翻訳。
2. **AIを過信しない「下書き ＆ 原文対照」UX**
   - 抽出された予定日、集合時間、持ち物、締切を登録前にプレビュー・編集可能。
   - 英語原文と日本語訳をいつでも並記して確認できます。
3. **直近の予定 ＆ 持ち物チェックリスト**
   - 直近の行事や集合時間、必要な持ち物をひと目で確認。
4. **⚠️ 提出物・同意書の締切アラート**
   - Permission Slipや集金袋などの返送期限をカウントダウン警告。提出済みチェック機能付き。
5. **Googleカレンダー連携 ＆ iCal一括エクスポート**
   - ワンクリックでGoogleカレンダーに予定・持ち物・締切を登録可能。
6. **LINE通知シミュレーター**
   - 前日・当日の持ち物や予定のリマインド通知をLINE風画面でテスト送信。
7. **日英バイリンガル全文検索**
   - 「水筒」「water bottle」「遠足」「permission」など日本語・英語どちらでもピンポイント検索可能。

## 🚀 起動方法

```bash
# ディレクトリに移動
cd C:\Users\mm\.gemini\antigravity\scratch\otayori-post

# サーバー起動
python main.py
# または run.bat をダブルクリック
```

起動後、ブラウザで **http://127.0.0.1:8000** にアクセスしてください。
スマートフォンからも同一ネットワーク内のIPアドレス（例: `http://192.168.x.x:8000`）で利用できます。
